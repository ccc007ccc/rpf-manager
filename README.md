# RPF Manager

轻量的 Android RAGE 资源查看器与 RPF7 文件管理工具。Kotlin / Jetpack Compose 双栏界面、本地 Rust 解析与独立 Vulkan 查看器；中文、英文和深浅色主题。支持直接浏览内部存储、系统文件／目录选择器、覆盖保存和另存。Android 11 及以上由用户在系统设置中授予“所有文件访问权限”后浏览内部存储根目录；旧版 Android 使用存储读写授权。不申请网络或独立媒体权限。

公开版本保留完整资源处理源码，面向熟悉 RPF / RAGE 格式的开发者。AES／NG 通用解密与用户密钥导入可用，**不附带游戏密钥、解密数据表、游戏资产或专有 TFIT 实现**。无需这些数据即可编译 APK、使用原创示例及处理未加密的资源；读取加密资源前须提供匹配的密钥，见 [密钥接口](docs/KEYS.md)。

Android 8.1 / API 27 起，当前 APK 支持 ARM64；3D 预览需要 Vulkan。项目版本 0.4.0，与 Rockstar Games / OpenIV 无隶属关系。项目代码采用 [MIT](LICENSE)，第三方来源与许可见 [THIRD_PARTY.md](THIRD_PARTY.md)。

## 功能范围

| 资源 | 当前行为 |
| --- | --- |
| RPF | 直接读取、嵌套包、搜索／筛选／排序、多选／全选／反选；RPF7 添加、批量替换与删除、重命名、新建目录、文本编辑、整批撤销／重做、覆盖保存和流式另存；AES／NG 由用户导入密钥；非标准 NG 目录尝试用户密钥集 |
| 双栏文件管理 | RPF 与内部存储或 SAF 目录并排浏览，可切换单栏；无需先打开 RPF 即可管理存储；目录导航、刷新、新建、重命名、删除、打开资源；递归名称搜索及子目录来源显示；批量导入／导出、同名批量替换及不同名单文件定向替换；冲突确认、进度、停止和部分结果 |
| 解包 / 打包 | 递归展开嵌套 RPF，逐文件直接写入系统选择的目录；拒绝覆盖同名目录；目录中的 `.rpf` 子目录重新打包为嵌套包；支持大文件、完整资源偏移、取消与临时目录清理 |
| ASTC 转换与修复 | 扫描目录内全部 RPF、统计 BC / ASTC 与保留原因；14 种块尺寸、6 档质量、自定义搜索强度 / RGBA 权重 / 透明优化；按 mip 和层数估算体积；新副本或逐包替换、后台进度 / 停止、JSON 报告；单独修复旧资源分页 |
| YTD / DDS | 纹理选择、颜色 / Alpha 通道、缩放 / 平移、PNG 导出；BC1–5、BC7 与常用未压缩格式；DDS 暂不显示立方体贴图和体积纹理 |
| YDR / YDD / YFT | PC RSC7 静态三角几何；最高可用 LOD、字典内模型、YFT 主 Drawable；轨道相机、线框、俯视 / 正面与网格；选择嵌入、包内或外部 YTD 贴图，按真实 UV0 采样 |
| YMAP | 从 Meta 数据解析实体的位置、旋转和缩放，以实体标记显示布局；空实体列表显示明确的空状态；不加载外部模型或显示遮挡、流式加载等其他地图数据 |
| YBN | 三角几何、BVH 几何、复合层级变换、球体与盒体；其他形状以明确标注的包围盒显示 |
| AWC | 音轨与编码信息；PCM16、Rockstar IMA ADPCM 与支持的流式分块音轨；播放、暂停、定位、WAV 导出；切页、后台、失去音频焦点或拔出耳机时停止播放 |
| PNG / JPEG / WebP / BMP、文本 | 图像预览；UTF-8 文本显示前 64 K 字符，最大 2 MiB，支持 SPS、列表及其他可识别的纯文本；包内文本编辑保留完整内容、BOM 和换行 |
| 解析报告 | 遍历当前 RPF 及嵌套包，实际调用预览解码器，分别统计可预览、部分支持、不支持、失败与包索引；单独提示未能展开的包，包内文件不计入统计；格式汇总、文件明细、停止扫描和 JSON 导出 |

模型贴图选择用于检查单张纹理在 UV0 上的效果，不自动组合游戏材质、法线贴图或骨骼动画；没有可读取 UV 的几何保留几何着色。新世代布局、压缩顶点等变体可能无法预览。AWC 音频加密、未知编码和大于 64 MiB 的解码音轨会明确提示限制。未知格式仍可查看信息并导出。

手机竖屏与横屏均可并排浏览 RPF 和存储目录，通过顶部标签选择当前操作栏，也可切换为单栏。授予内部存储访问后，启动即可浏览内部存储根目录，左栏尚未打开 RPF 时保留打开入口；也可从首页的“浏览内部存储”进入。长按进入多选，底部显示当前传输目标与操作；两栏分别保留目录和滚动位置。名称搜索包含当前目录的子目录，结果显示相对父路径；无法读取的存储目录会列出跳过原因。文件预览使用全屏，返回后继续管理文件。3D 中单指旋转、双指平移、捏合缩放，“适配视图”重置相机。紧凑首页优先显示打开入口与最近记录，下方为工具和示例工作区。示例包含原创模型、贴图、地图、碰撞和两条合成音轨，经过与用户文件相同的 RPF / RSC7 / AWC 解析路径，不含 GTA 游戏资产。

选中存储中的文件或目录即可批量导入 RPF；“替换同名文件”按名称和相对路径匹配，未匹配内容跳过。两栏各选一个文件后可定向替换，来源与目标不必同名，目标名称保持不变。选中 RPF 内的项目可批量导出到存储。执行前确认来源、目标和冲突策略，导入／导出默认跳过同名文件；完成后分别报告成功、跳过和失败。RPF 批量修改可一次撤销，存储中的删除与覆盖不能在此撤销。

工作区保留添加、新建目录、文本编辑、撤销／重做、解析报告，以及“覆盖保存”和“另存为”。嵌套包返回父包时保留修改；保存会将嵌套修改逐层带回主包，并写出新的 OPEN RPF7。另存保留原包和编辑历史，取消选择目标不会先折叠当前嵌套包。覆盖保存先确认目标；内部存储中的可写原包直接保存，SAF 原包尚未授权父目录时，请在系统目录选择器中选择原目录。覆盖流程先暂存、重开验证与校验摘要，再以恢复日志保护的重命名发布新包；成功后重新打开保存后的资源包，保留普通目录和筛选上下文。不能提供所需重命名和删除能力的存储服务会拒绝覆盖，仍可另存。关闭或打开另一份文件前提示未保存修改。不同文档提供器的覆盖能力由运行时检查；无法安全发布时请另存。

首页的“ASTC 转换与修复”使用系统目录选择器。默认输出到新目录，默认要求当前包转换后没有残留 BC；允许保留 BC 时会明确标为未完整转换。ASTC 使用私有 `AS + 块宽 + 块高` 标记，仅支持该格式的定制游戏可以使用。更改参数需从原始 BC 重新转换，已有 ASTC 会跳过；分页修复不重新编码纹理。

转换任务使用前台服务与有超时的唤醒锁，Android 13 及以上会请求进度通知权限；拒绝通知仍可在应用内查看任务。系统可能限制后台运行时间，完成的顶层包会保留。替换前写新文档、重开校验并计算摘要，使用恢复日志保护原包；存储服务不支持必要操作时会拒绝替换。副本模式会复制其他文件，失败或停止后可能留下不完整副本。

## 构建与验证

完整工具链版本、安装和 CI 步骤见 [构建说明](docs/BUILDING.md)。配置好 SDK / NDK、Java 17 和 Rust 后：

```bash
./scripts/build.sh assembleDebug testDebugUnitTest lintDebug
./linux/build.sh
```

APK 输出：`app/build/outputs/apk/debug/app-debug.apk`。所有原生库和 Vulkan 着色器从源码构建，公开构建不需要任何私有仓库、游戏数据或发布签名。SteamOS 上脚本使用现有的 `dev` Distrobox；普通 Linux 和 CI 使用当前环境。

Linux CLI、GUI 与 Android 共用同一核心，见 [Linux 使用说明](linux/README.md)。RSC7 解压恢复、资源分页、共享纹理数据和嵌套包处理的关键约束见 [资源处理说明](docs/RESOURCE_PROCESSING.md)。

## 代码入口

- `app/src/main/kotlin/com/gtav/rpfmanager/ui/`：资源库、工作区、预览、设置与本地矢量组件。
- `viewmodel/ArchiveViewModel.kt`：导航、任务取消、预览与导出状态。
- `data/repository/RpfRepository.kt`：SAF 描述符、单文件暂存、最近记录与密钥。
- `data/repository/WorkspaceFiles.kt`、`ArchiveOverwrite.kt`：授权目录导航、批量传输、冲突处理与原包覆盖发布／恢复。
- `app/src/main/cpp/`、`preview/VulkanView.kt`：独立渲染器、相机、Surface 生命周期。
- `rust-core/jni-bridge/`：JNI、索引、编辑历史/流式写入、音频、解析统计、预览数据契约与测试。
- `app/src/main/kotlin/com/gtav/rpfmanager/astc/`：转换界面、前台任务、SAF 文件操作、替换恢复日志与结果报告。
- `rust-core/jni-bridge/src/conversion*.rs`、`transcode*.rs`：Android / Linux 共用的递归转换、分页修复、校验与估算；`astc_preview.rs` 与归档库的 BC 解码器用于预览及解析报告。
- `rust-core/rpf-archive/`：直接纳入仓库的上游源码及本地修复，来源见 [第三方说明](THIRD_PARTY.md)。
- `linux/`：同一核心的 CLI 与 Tk 界面，构建方法见 [Linux 说明](linux/README.md)。

英文默认资源位于 `res/values/strings.xml`，中文位于 `res/values-zh/strings.xml`。新增界面文案必须同时补全两种语言；文件名、扩展名和原始诊断不作翻译。语言切换使用独立 Configuration，不修改系统语言。

## 资源与数据

打开文件时，Rust 保留系统文件选择器提供的描述符并只读映射，不复制整包。未压缩、未加密的嵌套 RPF 共享同一映射；压缩／加密的嵌套包在上限内解码到内存。原始名称保留用于 NG 解密。导入或编辑时只暂存受修改的单文件，描述符随撤销记录保留；另存按 256 KiB 缓冲写出，写入前检查目标身份，拒绝用另存目标直接截断正在打开的源文件。另存取消或失败可能留下不完整目标文件，工作区修改仍可重试。

显式覆盖保存使用独立的新包发布流程，准备与校验阶段保留原映射和重试所需编辑数据。发布阶段先保留原包恢复副本，再重命名新包；日志用于异常和重启后的恢复，发布阶段不接受中途取消。批量导出覆盖已有存储文件也使用恢复日志。本地存储操作限制在当前浏览根内，拒绝符号链接越界，并保护仍在使用的源文件和编辑来源；SAF 操作使用已授权目录。所有文件访问权限仍受 Android 对其他应用私有目录的限制，搜索会报告无法读取的目录。

批量取消会尽快停止后续项目；正在执行的目录删除或文件发布可能需要完成当前步骤后才能结束，不保证在每个字节处立即中止。递归搜索使用独立任务取消，不会改变批量操作的取消状态。

预览文件 / RSC7 解压上限 256 MiB，单纹理上限 16 megapixels，模型贴图上传的最长边缩放到最多 2048 像素，网格上限 100 万顶点 / 200 万三角面。编辑受 RPF7 的名称表、文件大小和数据偏移限制；历史最多 40 步，并按索引总量收紧。扫描最多 24 层嵌套、10 万个文件条目，到达上限或停止时标明报告未完成。文本和图像预览成功不意味着完整理解其游戏语义，模型成功表示静态几何可读；报告保留具体解析口径与诊断。

解析报告 JSON 的 `schema: 2` 区分扫描结束与覆盖完整：`finished` 表示未因取消或扫描上限提前停止；`unopenedArchives` 表示已发现但无法打开的嵌套包数量；只有扫描结束且所有已发现的嵌套包均已展开，`complete` 才为 `true`。未展开包内的文件数量未知，不参与统计。实体标记、空实体地图和简化碰撞均归为部分支持。

密钥仅存储在应用的 `noBackupFilesDir`；设置可移除密钥和清理未使用缓存。最近记录存 URI 权限与原始名称，示例不会伪造最近记录。清理缓存保留当前打开的工作区。

公开版的测试使用程序生成的合成资源。通用解密和特殊 NG 目录重试有合成回归；不能将这些测试视为所有游戏版本或所有加密包已经验收。加密包仍需要匹配的用户密钥。
